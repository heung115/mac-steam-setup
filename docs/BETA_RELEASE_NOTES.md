## 이번 베타의 변경 사항

- macOS의 선호 언어에 따라 앱 전체가 한국어 또는 영어로 자동 전환됩니다.
- 설치 진행·오류 메시지와 생성된 게임 바로가기의 경고도 같은 언어를 사용합니다.
- 한국어 환경에서는 Steam 상점의 한국어 게임 이름을 표시하고, 영어 환경에서는 영문 이름을 유지합니다.
- 영어 문구가 잘리지 않도록 화면 폭과 사이드바 문구를 조정했습니다.

## 설치

1. `Mac-Steam-Setup-*.dmg` 파일을 받습니다.
2. DMG를 열고 `Mac Steam Setup.app`을 함께 보이는 `Applications` 폴더로 드래그합니다.
3. 앱을 한 번 실행해 봅니다.
4. macOS가 차단하면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택합니다.

이 베타는 Apple의 서명·공증을 받지 않았습니다. 배포 DMG와 대체 ZIP에는 Mac Steam Setup 앱만 들어 있으며 Steam, Wine, Windows 게임, Sikarugir 엔진·템플릿 또는 D3DMetal을 포함하지 않습니다.

## What's new in this beta

- The entire app now follows the preferred macOS language in English or Korean.
- Setup progress, errors, and generated game-shortcut alerts use the same language.
- Korean systems can show Korean Steam Store game names, while English systems keep English names.
- Window sizing and sidebar labels were adjusted to prevent English text from being truncated.

## Installation

1. Download `Mac-Steam-Setup-*.dmg`.
2. Open the DMG and drag `Mac Steam Setup.app` onto the `Applications` folder shown beside it.
3. Try to open the app once.
4. If macOS blocks it, choose **System Settings → Privacy & Security → Open Anyway**.

This beta is not signed or notarized by Apple. The DMG and fallback ZIP contain only Mac Steam Setup; they do not include Steam, Wine, Windows games, Sikarugir engines or templates, or D3DMetal.
