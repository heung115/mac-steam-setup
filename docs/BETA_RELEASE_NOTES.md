## 설치

1. `Mac-Steam-Setup-*.dmg` 파일을 받습니다.
2. DMG를 열고 `Mac Steam Setup.app`을 함께 보이는 `Applications` 폴더로 드래그합니다.
3. 첫 실행은 앱을 우클릭(또는 Control-클릭)하고 **열기**를 선택합니다.
4. 계속 차단되면 앱을 한 번 실행해 본 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 선택합니다.

이 베타는 Apple의 서명·공증을 받지 않았습니다. 배포 DMG와 대체 ZIP에는 Mac Steam Setup 앱만 들어 있으며 Steam, Wine, Windows 게임, Sikarugir 엔진·템플릿 또는 D3DMetal을 포함하지 않습니다.

## Installation

1. Download `Mac-Steam-Setup-*.dmg`.
2. Open the DMG and drag `Mac Steam Setup.app` onto the `Applications` folder shown beside it.
3. On first launch, right-click or Control-click the app and choose **Open**.
4. If it is still blocked, try opening it once, then choose **System Settings → Privacy & Security → Open Anyway**.

This beta is not signed or notarized by Apple. The DMG and fallback ZIP contain only Mac Steam Setup; they do not include Steam, Wine, Windows games, Sikarugir engines or templates, or D3DMetal.
